# Черновик поста от лица Анны

У меня на компьютере появился офис с ИИ-агентами. И они ходят за кофе ☕

Я подключаю своих агентов, даю им задачи в привычных инструментах и открываю отдельное окно с маленьким 3D-офисом. Один персонаж читает, другой правит файл, третий выполняет команду. Можно нажать на сотрудника и посмотреть его последнее действие.

Так мне проще одним взглядом увидеть, от кого недавно приходили события, где работа завершилась, а где давно нет обновлений.

Мы упаковали этот офис в отдельный открытый проект — Agent Office. Для него не нужна моя папка с постоянной памятью, IvanOS или какая-то особая структура компьютера.

Для Windows есть готовый архив: скачали, распаковали, открыли приложение, выбрали журналы своих агентов — и подключили файл состояния в браузере. А чтобы просто посмотреть, достаточно открыть HTML и включить демо.

Работает с локальными журналами Codex и Claude. Другие инструменты можно подключить через простой JSON состояния. Всё происходит на вашем компьютере; сам офис не обращается к моделям и не требует API-ключей.

Кофе и прогулки — анимация. Рабочие статусы берутся из событий подключённых агентов. Когда данные устаревают, это видно. Задачи по-прежнему задаются в самих инструментах: офис помогает наблюдать за командой.

Код открытый, можно скачать и переделать под себя. Инструкция и готовая версия здесь:

https://github.com/psimonov1993-blip/agent-office
