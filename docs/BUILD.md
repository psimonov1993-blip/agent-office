# Сборка Windows-архива

Готовая версия включает Python и Tkinter. Исходники для запуска не требуют сторонних Python-библиотек; PyInstaller нужен только сборщику.

На Windows x64, в корне репозитория:

```powershell
py -3 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python build_release.py
```

Результат: `dist/Agent-Office-Windows-x64.zip` и файл SHA-256 рядом. Скрипт использует явный список файлов; конфигурация, настоящие журналы, `.runtime`, Git-история и локальное окружение в архив не попадают. Повторная сборка откажется перезаписывать существующую папку сборки: переместите прежний результат или используйте свежую рабочую копию.

Готовое приложение ищет `index.html` и `vendor` рядом со своим EXE, поэтому распространяйте весь архив. Для macOS/Linux доступен запуск исходников. PyInstaller не является кросс-компилятором; нативные сборки для этих систем в этот релиз не включены.

Проверка архива: распаковать в новую папку с пробелами и нелатинским именем, запустить EXE с `--config путь-к-тестовой-конфигурации --once`, проверить созданный снимок; открыть `index.html#demo` в браузере без доступа к сети. После этого проверить графический мастер. Настоящие журналы для сборки и smoke-теста не нужны.

[Документация PyInstaller](https://pyinstaller.org/en/stable/usage.html).
