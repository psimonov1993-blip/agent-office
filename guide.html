Вернуться в офис

Поселите своих агентов в офисе

Без IvanOS и системы памяти. Офис работает локально и показывает события из файлов, которые вы выберете.

Сначала просто посмотрите

Демо работает без установки и настройки. Персонажи читают, работают за столами и ходят за кофе. События вымышлены и явно помечены.

Открыть демо

1. Откройте мастер подключения

Готовый архив для Windows: распакуйте всю папку и дважды нажмите Agent Office.exe.

Исходники: установите Python 3.10 или новее с Tkinter. В Windows откройте Start Office.cmd. На macOS и Linux выполните в папке python3 office.py. На Linux для окна настройки может понадобиться пакет python3-tk.

Сначала запустите агента и дайте ему задачу в его обычном приложении. Офис только наблюдает.

2. Выберите журнал своего агента

Нажмите «Добавить Codex» или «Добавить Claude». Мастер покажет имена недавних журналов с временем изменения. Выберите нужную сессию. Если её нет, нажмите «Выбрать другой файл».

Укажите имя для персонажа. Через «Изменить» можно добавить свою подпись к задаче. Она не отправляется агенту. Для другого инструмента выберите «Другой агент (JSON)»; формат описан в README и docs/INTEGRATIONS.md.

Обычно локальные журналы находятся в ~/.codex/sessions и ~/.claude/projects. Это внутренние форматы приложений: их расположение и события могут меняться. Если ваша версия не создаёт такие журналы, используйте JSON состояния.

3. Подключите живой файл в браузере

  1. Нажмите «Запустить офис». Откроется Chrome или Edge.
  2. В мастере нажмите «Скопировать путь к файлу».
  3. В браузере нажмите «Подключить живые данные». В диалоге выбора вставьте скопированный путь и откройте файл agent-office.json.

На macOS в диалоге файла используйте Cmd+Shift+G, чтобы перейти по пути. На Linux скрытая папка .runtime обычно показывается через Ctrl+H.

Браузер просит выбрать файл при каждом новом открытии страницы. Это обычное разрешение на чтение выбранного снимка.

Оставьте мастер открытым

Он обновляет файл каждые 2 секунды и останавливается через 2 часа. Чтобы продолжить, снова нажмите «Запустить офис». Закрытие мастера или кнопка остановки прекращают наблюдение.

Что означают статусы

  • Читает / Правит файл / Выполняет команду — последнее распознанное событие агента.
  • Свежая активность — событие есть, конкретное действие не определено.
  • Завершено — получено событие завершения, а не гарантия качества результата.
  • Нет свежих событий — более 90 секунд без рабочей активности.
  • Снимок устарел — мастер не обновлял файл больше 15 секунд.
  • Нет данных — файл не читается или нет понятных событий. Подробности видны в мастере.

Если что-то не появилось

Пустая комната: нажмите «Посмотреть демо» или подключите живой снимок. Неподключённые агенты не придумываются.

Не удаётся подключить файл: используйте настольный Chrome или Edge. Выбирайте .runtime/agent-office.json, а не исходный журнал .jsonl и не config.json.

Новая задача не появляется: новая сессия агента часто создаёт новый журнал. Остановите наблюдение, удалите прежний источник и выберите новый.

Не работает 3D: распакуйте весь архив, оставьте vendor рядом с index.html и проверьте поддержку WebGL в браузере. Даже без 3D список статусов остаётся доступен.

Персонажи не двигаются: проверьте паузу и системное уменьшение движения. «Открыть снимок» специально показывает неподвижную копию.

Прогулки, разговоры и кофе — визуальная метафора. Офис не читает экран, не задаёт поручения и не управляет процессами агентов.
