## Windows distribution

The optional Windows archive bundles Python and Tcl/Tk through PyInstaller. Their license notices are included in `licenses/` in the generated archive. PyInstaller's bootloader exception permits distributing the bundled application under its own license.

[Python license](https://docs.python.org/3/license.html) · [PyInstaller license](https://pyinstaller.org/en/stable/license.html).

`vendor/TCL-LICENSE.txt` is the Tcl 8.6.12 notice, used when the Windows Python installation omits a separate Tcl license file. [Upstream notice](https://github.com/tcltk/tcl/blob/core-8-6-12/license.terms).
