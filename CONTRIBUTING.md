# Как помочь проекту

Исправления адаптеров, доступности и переносимости приветствуются. В issue опишите ОС, браузер, версию Python/приложения и шаги воспроизведения. Не прикладывайте настоящие журналы переписки, `config.json`, `.runtime`, ключи или токены. Для примеров используйте синтетические события.

Перед PR выполните `python -m unittest discover -s tests`. Для изменений сцены также выполните `python tests/browser_checks.py` после установки `requirements-test.txt` и Chromium через Playwright.

Сохраняйте локальную работу без CDN и runtime-зависимостей pip. Не выдавайте демонстрацию за реальные данные; не переносите тексты сообщений из журналов в снимок. Изменения формата JSON должны учитывать `schema_version` и документироваться в `docs/INTEGRATIONS.md`.
